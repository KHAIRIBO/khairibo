# Khairi Portfolio (React + Node.js + Supabase)

This project is a React single-page app served by Node.js (Express) with Supabase backend integration.

## Stack
- React (browser ESM)
- Node.js + Express
- Supabase (PostgreSQL database)
- Vanilla CSS

## Features
- White/caramel hero design
- Language switcher: EN / FR / AR
- RTL support for Arabic
- Hidden admin access: click logo 3 times, then enter password
- Database-backed pages (Projects, About, Contacts)
- Contact form submission to Supabase

## Routes
- `/` home page
- `/projects` fetch and display projects from Supabase
- `/about` fetch and display about info from Supabase
- `/contacts` contact form that submits to Supabase
- `/data` local test data page (password storage)
- `/admin` protected admin page

## Database Setup

Create these tables in your Supabase database:

### projects
```sql
CREATE TABLE projects (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  title VARCHAR NOT NULL,
  description TEXT NOT NULL,
  link VARCHAR,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### about
```sql
CREATE TABLE about (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  bio TEXT NOT NULL,
  skills VARCHAR,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### contacts
```sql
CREATE TABLE contacts (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  name VARCHAR NOT NULL,
  email VARCHAR NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### contact_submissions
```sql
CREATE TABLE contact_submissions (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  name VARCHAR NOT NULL,
  email VARCHAR NOT NULL,
  message TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);
```
